PSE Sonora é um projeto acadêmico desenvolvido em linguagem C que propõe um sistema de apoio à organização de ações educativas sobre saúde auditiva no ambiente escolar. O sistema permite cadastrar, consultar e acompanhar atividades voltadas à conscientização sobre o uso responsável de fones de ouvido, auxiliando no planejamento e controle das ações realizadas pela iniciativa fictícia PSE Sonora.
